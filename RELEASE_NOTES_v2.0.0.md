# Windows App Locker v2.0.0

Version 2.0.0 turns the original single-file Windows App Locker into a complete GitHub-ready project while retaining its core behavior.

Highlights:
- searchable Windows dashboard and safer app management;
- temporary unlock with PIN and configurable duration;
- Telegram owner-only commands plus inline control menu;
- DPAPI-protected Telegram token and PBKDF2 PIN record;
- transparent per-user autostart and system-tray operation;
- diagnostics, config recovery, notification throttling, installer/uninstaller, CI, release checks, and documentation.

The application remains a user-level locker. Windows Administrators retain full control over the machine.
